# PhiNet R0.2 · Paired synthetic computational placement study

**SIMULATED / authority NONE / offline.** R0.1 remains an isolated
advisory simulator. R0.2 adds a compute-rate-only baseline to the same
scheduler (same default and original two-policy CLI demonstration), plus a
fixed generated workload census. No live adapters or external dependencies.

## Frozen design

9 workload families × 27 integer seeds (369 + 97*i, i=0..26) × 3 policies
= **243 paired scenarios / 729 simulated plans**. First nine seeds per family
are development-labelled; remaining 18 are holdout-labelled. No tuning step
exists; both cohorts are generated by the same authored distribution and
neither is independent external data. The full design is visible in source.

Families: balanced, hot-model skew, no resident models, low link rate,
static worker outage, private-task skew, tight capacities, fan-out/join,
and an intentionally constructed affinity trap. The last family deliberately
shows a greedy scheduler delaying a private origin-pinned job. A link-rate
parameter is not concurrent shared-link contention. No dynamic failure,
recovery, deadlines or output transfers are modeled.

All policies share identical DAGs, task order, hard constraints, costs,
one active job per worker and fixed resident model sets. First-fit selects
lexical first eligible idle node, compute-rate selects fastest eligible
idle node ignoring staging/link in its ranking, locality uses R0.1's full
estimated duration then cold/network bytes. None performs lookahead.

## Outputs

    python -m phicloud.phinet_study > phinet-r02-report.json
    python -m unittest discover -s tests -p 'test_phinet*.py' -v

Report preserves every scenario, input digest, policy summary, receipt
digest, and per-family/per-split signed paired deltas (locality minus
baseline). Negative is better for the four cost metrics; wins, ties, losses,
median, minimum and maximum are preserved. Equal placed-task identity is
mandatory before comparing costs. Cold MiB and network MiB are modeled
transfer quantities; GPU job ticks include staging and waiting terms,
not measured GPU busy time, energy or VRAM savings. A separate arithmetic
audit checks coverage, capacity, privacy, timing, DAG and nonoverlap, but
does not independently reimplement the scheduling policy or prove every
HOLD justified. Replay regenerates the entire fixed report. No authenticity
or general statistical inference is claimed.
